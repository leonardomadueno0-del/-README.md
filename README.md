# Calcular el IMC(Indice de Masa Corporal)

## Integrantes del Equipo
Leonardo Madueño Mariscal

## Descripción
Este proyecto consiste en un programa desarrollado en Python que calcula el **Índice de Masa Corporal (IMC)** de un usuario de forma rápida y sencilla.

## Uso de IA 
No necesite utilizar la IA para este proyecto porque creo que es un proyecto facil y que ya puedo hacer yo solo, ademas en VScode si tienes un error en el codigo te dice hay mismo que esta el error.
